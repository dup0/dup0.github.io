Overview

What is duping?

Duping means turning one in-game item into two. DHG dupe is a mod built for exactly that on TrexMine: hold an item, type /dupe, and keep both copies.

×2

Features

Built for one job

One command

Hold the item, open chat and type /dupe. No menus, no keybinds, no config files.

Made for 1.21.11

Built against Minecraft 1.21.11 so it stays in sync with the current server build.

Four steps from download to your first duplicate on TrexMine.
