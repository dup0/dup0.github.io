What is duping?

Duping is the duplication of in-game items: one becomes two. DHG dupe is a mod made for this purpose on the TrexMine server.

Installation & usage

  1. 1

    Download

    Get the mod file (version 1.21.11) using the download button.

  2. 2

    Install

    Copy the file into the mods folder of your Minecraft 1.21.11.

  3. 3

    Join

    Launch the game and connect to the server.

  4. 4

    Dupe

    Hold the item in your hand and type /dupe in chat.
